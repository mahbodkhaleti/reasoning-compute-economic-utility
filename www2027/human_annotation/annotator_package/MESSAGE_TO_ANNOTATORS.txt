What you'll do

For each one, you record what the model wrote. You are not judging whether it was right:
1. For each option: did the text write a result for that option's expected profit (Y/N)? If yes, what number did it write?
2. For each text: did it give a result for every option? Which option has the largest number it wrote? Did it state which option it would choose?
